# Learning Resources

If you are new to PlatformIO, you can start by watching the [Basics of PlatformIO (PIO)](https://www.youtube.com/watch?v=JmvMvIphMnY) video on YouTube.

For more details and full documentation, visit the [PlatformIO Docs](https://docs.platformio.org/en/latest/).

To learn the basics of Git and GitHub, you can watch this [Git & GitHub basic tutorial](https://www.youtube.com/watch?v=DVRQoVRzMIY).
