# ESP32 OTA Update Server (Flask)

This is a simple OTA (Over-the-Air) firmware update system using Flask and two ESP32s.

📁 Directory Structure:
.
├── access_point/           # ESP32 code to create Wi-Fi Access Point
│   └── access_point.ino
├── receive/                # ESP32 code that connects to AP and receives OTA updates
│   └── receive.ino
├── firmware/
│   └── firmware.bin        # Compiled firmware for the receiver ESP32
├── main.py                 # Flask OTA update server (runs on laptop)
├── update.py               # Optional script to upload firmware
└── README.md               # This file

📋 Instructions:

1. Flash `access_point/access_point.ino` to one ESP32 — this creates a Wi-Fi Access Point.
2. Flash `receive/receive.ino` to the second ESP32 — this will:
   - Connect to the Wi-Fi AP created by the first ESP
   - Contact the Flask OTA server for updates

3. On your laptop:
   - Connect to the AP Wi-Fi network hosted by the first ESP.
   - Start the OTA server:
     python3 main.py

4. Compile the firmware for the **receiver ESP** and place the binary as:
   firmware/firmware.bin

5. Upload the firmware to the OTA server:
   curl -X POST -F "file=@firmware/firmware.bin" -F "version={version}" http://192.168.0.50:5000/upload
